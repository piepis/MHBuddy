# MH伙伴助手产品说明

本文给产品、内容和验收使用。它说明这个 Web 应用是给谁用的、和现有伴侣工具差在哪里、现在能做什么、还不能做什么。

阅读时先记住三件事：

- **当前构建是夹具预览。** 百科数字、地图点、活动和公开配装都带 `fixture` 标记，用来把流程跑通。它们不是《怪物猎人》实数，也不能拿来和游戏对答案。
- **还没有公网站点。** 仓库可以在本机预览。对外 HTTPS、免安装打开链接，要等站点发布之后才算数。
- **竞品只写 2026-11-23 核对过的公开页。** 来源互相打架、页面没写全、或这次没打开的句子，一律标「待复核」，不补成事实。摘要在 [execution/mh-mobile-parity.md](execution/mh-mobile-parity.md) 和 [execution/gamersky-parity.md](execution/gamersky-parity.md)。

MH伙伴助手不是卡普空的官方应用，也不是《MH伙伴：世界／冰原》或《MH伙伴：荒野》的网页移植，更不是游民星空工具的镜像。

## 1. 产品定位与目标用户

### 定位

MH伙伴助手是一个用浏览器打开的非官方伴侣。一个站点同时覆盖两部作品：

- 《怪物猎人：世界》，冰原是它的内容档，不是第三部作品。
- 《怪物猎人：荒野》。

猎人不用安装客户端。打开链接就能查百科、看当前作品的活动、在世界地图上找夹具采集点、用夹具规则做配装。选中的资料可以下载到这台浏览器，之后在已缓存的范围内离线看。登录后的账户可以在额度内同步自己的记录。公开配装用链接分享；没发布的私稿不出现在公开地址上。

界面默认是浅色羊皮纸，可选深色。世界和荒野用名称和圆点区分，不靠换主题区分。窄屏底栏、宽屏顶栏都是四项：首页、百科、配装、我的。活动从首页进入，世界地图从首页和素材正文进入。文案有简体中文、繁体中文、英语、日语。

### 目标用户

| 谁 | 想完成的事 |
| --- | --- |
| 桌面或手机上的猎人 | 点开链接就查，不先装 App，也不先登录 |
| 两作都玩的人 | 在同一个站点切换世界／冰原和荒野，筛选各自保留 |
| 只想暂存的人 | 收藏和配装先留在这台浏览器 |
| 多设备的人 | 登录后按账户同步，并看到额度 |
| 从群里点链接的人 | 直达某一条百科、活动或已经公开的配装 |

不把下面的人当作这一版已经服务好的用户：要拿这里的数字当游戏实数的人；要在网页里做机械武器、猫饭或极限突破模拟的人；要查招式动作值的人。这些要么还没有实数，要么公开对照里没有做成我们的功能，见第 6、7 节。

### 这一版故意不做的产品承诺

- 不承诺数据吻合 98% 或 99%。那两个百分比是两款 MH伙伴商店简介里的营销口径，不是本站的审计结果。正式资料还没有发行清单，准确度审计没有输入。
- 不承诺已经可以公网匿名访问。
- 不设价格，也不接真实支付。开发环境里的额度只为验证「空间够不够」。
- 不收录崛起、物语等系列作品。公开系列站提到过它们，本站范围只有世界（含冰原）和荒野。

### 2.3 差异化（只保留能站住的）

本站相对两款 App 和游民工具，产品上要站住的是这几条：

1. **一个链接覆盖两作。** 世界／冰原和荒野不用各装一个 App。游民当天没有检到自有的世界／冰原图鉴或配装器。
2. **先匿名，再选择要不要账户。** 首页、百科、地图、活动、已发布配装不要求登录。收藏和私稿先留在这台浏览器。同步才要账户和额度。
3. **公开配装和私稿分开。** 发布出去的是一份快照。作者后来改自己的稿，不改已经公开的那一份。撤回之后，公开地址不再给出装备。游民多出来的是社区大厅和招式动作值；两款 App 多出来的是完整客户端、真实资料和各自的模拟器。
4. **世界采集点走自己的地图。** 首发地图只做世界／冰原。荒野百科可以保留已核对的获取地点，但不把「荒野也有地图页」写成已确认功能。
5. **浏览器里更新资料包。** 清单要验签、对哈希，失败就继续用上一版。这和「装一个会在线更新的 App」是同一类需求，换到了浏览器。

不要写成差异化的句子：

- 「我们比 App 更准确。」没有实数审计。
- 「游民没有世界工具，所以世界上只有我们。」2019 年游民攻略推荐过站外的 Armor Set Search 等工具。那不是游民托管的，也不等于世界上没有别的网页配装器。
- 「安卓和 iOS 功能一致。」应用宝和 App Store 的版本、简介并不总是同一段文字。

### 3.2 用户故事

下面每条都标了现在能不能走完。

1. **查一条资料。** 作为访客，我想搜索武器、怪物或素材并打开正文，以便不用装 App 就看这条夹具写了什么。已有页面。
2. **换一部作品再查。** 作为两作都玩的人，我想切到荒野后看到荒野的条目，再切回来仍是世界，以便不用记两个网址。已有页面。筛选是否在切换后各自保留滚动位置，这版没有单独验收，待复核。
3. **从素材跳到世界采集点。** 作为访客，我想在世界素材上点「地图查看」，落到对应层和标记，再回到素材。已有页面。标记是夹具点。
4. **按任务名或报酬找活动。** 作为访客，我想用名称搜一次、用报酬再搜一次，两次都落到同一条活动，以便确认奖励和截止时间。夹具活动可以。时间不是卡普空官方日程。
5. **用自己的珠子试一套。** 作为访客，我想打开「只用我的装饰品」并改珠子数量，以便看库存不够时没有结果、够的时候有一套。世界夹具可以。不能自选任意技能。
6. **给荒野留一个武器孔。** 作为访客，我想预留武器孔再求解，以便结果里武器孔仍空着，防具孔另计。荒野夹具可以。
7. **先在这台电脑存起来。** 作为访客，我想把当前结果存成我的配装，以便回头再看。可以写入内存。刷新页面会丢，这是已知缺口。
8. **把公开链接发给别人。** 作为访客，我想打开一条已发布配装并复制网址。已有页面。复制的是当前网址。
9. **不让别人看见我的草稿。** 作为所有者，我的私稿只留在自己的账户里。别人用公开地址打开这条 id，应看到没有记录，而不是装备表。浏览器验收覆盖了这条。
10. **换一台浏览器找回已同步的记录。** 作为会员，我想登录后看到额度，并把配装推到账户里，以便另一台只读到自己的记录。开发登录和同步接口可以。页面没有做成「换机恢复」向导，也没有真实账号。
11. **撤回发错的配装。** 作为该条的所有者，我想撤回后让旧链接不再展示装备。接口会这样做。页面上还没有撤回按钮。
12. **下载后断网仍能查。** 作为访客，我想下载资料包，关掉网络再打开同一条百科和地图。下载页面有。断网冷启动没有写进当前浏览器验收记录，待复核。

## 4. 核心流程

### 4.1 第一次打开

1. 打开站点根路径 `/`。不要求登录，也不要求先下完整包。
2. 选「世界」或「荒野」。
3. 首页三张卡：活动任务、资料、以及仅世界才有的地图。没有进行中的活动时，活动卡写「当前没有限时任务」。
4. 搜索框把关键词带到这部作品的百科列表。

深链可以直接打开，不必先回首页：

| 地址 | 打开什么 |
| --- | --- |
| `/g/:gameId/entries/:kind/:entryId` | 百科正文 |
| `/g/:gameId/events/:id` | 活动 |
| `/g/:gameId/maps/:mapId` | 世界地图 |
| `/builds/:publicId` | 已发布配装 |

刷新、复制链接应落在同一条。已撤回或不存在的公开配装不渲染装备。

### 4.2 查百科，再到世界地图

1. 在百科里按类型筛选，点一条进入正文。
2. 正文列出说明、要点和关联。点关联进入下一条。
3. 世界素材若带采集点，出现「地图查看」。
4. 地图可选层，可开关稀有采集。点标记看区域、条件和「查看素材」。
5. 窄屏地图隐藏底栏，避免挡住标记。返回用顶栏。

荒野素材不提供这张地图。

### 4.3 配装

1. 进入当前作品的配装页。浅色是说明卡；深色是「配装推荐 / 配装器」两个页签。
2. 世界可切换是否只用库存，并在 1 颗和 2 颗装饰品之间改。荒野可开关「预留武器孔」。
3. 点「搜索配装」。深色主题另有「停止搜索」。
4. 有结果时列出装备、珠子和空孔，并可「保存当前配装」。无解、条件冲突、未搜完，文案分开，不把中断说成无解。
5. 需要从文件看一套时，粘贴 JSON，先预览。确认写入还没有做成独立步骤；预览失败不会改已有记录。
6. 大厅入口打开夹具公开配装。底部有「复制到我的配装」和「复制链接」。前者尚未写入个人库。

两套规则分开。世界不接受荒野的预留孔。荒野求解用荒野夹具技能。

### 4.4 活动和离线包

1. 首页活动卡进入详情，或到活动列表用名称、报酬搜索。
2. 详情显示标题、核实时间、条件和起止。夹具条件里写明这不是官方时间。
3. 「查看更新」或「我的 / 离线资料」按作品下载。清单验签名和哈希。不通过就不换已激活的版本。
4. 世界和荒野的包分开。删一个包不应删另一作。当前删除入口只覆盖该次安装结果。

提醒的产品流程（关注、推送、拒绝权限后退回网页、下载日历）在规格里。这版页面还没把订阅和日历按钮接上。接口已经能登记订阅、也能下载日历文件。

### 4.5 登录、同步、发布

这条只在开发开关打开时走得通。正式环境不提供测试登录。

1. 「我的」里未登录显示「访客」，说明收藏和配装在这台浏览器。
2. 点「登录以同步」后，用开发账户建立会话，并显示额度。
3. 配装要同步时，客户端把待发送的变更推上去。超额被拒绝，不写入超出的部分。修订对不上则冲突，不覆盖服务器那一版。
4. 退出后会话作废，界面回到访客分区。
5. 发布会新建一条公开快照，调用者成为所有者。撤回只允许所有者。撤回后公开读取不再返回快照。

登录后把「这台浏览器里的访客数据」并进账户，规格里要先问用户。这版页面没有这一步。

## 5. 访客、会员与所有者

这里的三种身份是**用这个站点的人**。发布公网的人是另一角色，见第 6 节，不在这张表里。

- **访客：** 没有本站会话。可以看所有公开页，可以在这台浏览器留下收藏和未同步的配装。
- **会员：** 有本站会话的账户。当前只有开发登录能变成会员。额度由服务端记，不是页面自己填的。开发用户里，`hunter-b` 是小档 800 字节，其他开发用户是 20000 字节。这不是售价。
- **所有者：** 发布某一条公开配装的那个账户，或个人记录所属的那个账户。所有者是会员里的一种关系，不是第三个登录入口。别人登录了也不是这条的所有者。
- **管理员：** 能打开运营看板的账户。由环境变量 `MH_ADMINS` 或进程参数 `--admin` 点名，不是注册时自选，也不是「我的」页面里的身份。没有出现在这份名单里的访客和会员，访问 `/admin` 和 `/v1/admin/metrics` 都是 404。

| 动作 | 访客 | 会员 | 所有者 |
| --- | --- | --- | --- |
| 看首页、百科、世界地图、活动、未撤回的公开配装 | 可以 | 可以 | 可以 |
| 收藏、改本机库存、存未同步配装 | 可以，只在这台浏览器 | 登录后切到该账户的分区 | 同会员 |
| 看会员额度、推送或拉取同步 | 不可以。匿名同步返回 401 | 可以。超出额度的那条被拒绝 | 同会员，且只能动自己的记录 |
| 读另一个账户的私稿或同步快照 | 不可以 | 不可以 | 只能读自己的 |
| 用公开地址打开别人的私稿 id | 看到没有这条公开记录 | 同左 | 同左。私稿不走公开地址 |
| 发布一条公开配装 | 不可以，401 | 可以，并成为该条所有者 | 可以再发新的一条 |
| 撤回一条公开配装 | 不可以 | 不是这条的作者则 403 | 可以。之后公开读取为已撤回，不带装备快照 |
| 改别人已经发布的快照 | 不可以 | 不可以。作者改自己的私稿也不改旧快照 | 不能改已发出的快照，只能撤回 |
| 订阅活动提醒 | 接口允许，但必须带这台浏览器的撤销凭证 | 接口把订阅绑到账户 | 同会员 |
| 取消别人的提醒 | 不可以 | 只能取消自己的 | 同会员 |
| 付款升级 | 没有 | 没有真实支付 | 没有 |
| 看运营看板 | 404 | 不在管理员名单里则 404 | 同会员。名单里的账户才能看聚合 |

看板只汇总：新账户和活跃、留存、世界 / 冰原 / 荒野、武器和目标怪物、玩法风格、访客后来登录的数量、AI 次数和同步空间、热门搜索、热门公开配装。可以按日期筛选。一个分组少于 5（可用 `MH_ANALYTICS_K` 改）时，这一组不显示。AI 记录默认只有结构化条件和条目 id，不保留原句。埋点使用随机访客 id，不保存 IP 明文。这些还不是公网运营数据。

公开页不要求 Cursor 账户、团队邀请或访问密钥。站点能不能被公网打开，是发布设置，不是这张权限表。

会话用 HttpOnly Cookie。写请求若带了来源，必须和本站主机一致。个人数据的响应不让公共缓存保存。Service Worker 不缓存 `/v1/`。

## 6. 已实现与待做路线图

任务台账里，工程任务 T00–T08 和浏览器抽查 T10 已完成。T09（正式资料审计）和 T11（公网发布）停在外部条件上。下面按猎人能感知的顺序排，不按内部任务号排。

### 6.1 已经落地（夹具）

猎人在本机预览里可以：

- 切换世界和荒野，切换浅色和深色，切换四种界面语言。
- 搜索并打开夹具百科，从世界素材进入夹具地图。
- 用夹具规则求解，荒野可预留武器孔，世界可按装饰品数量限制。
- 预览荒野配装 JSON。
- 查看夹具活动，用名称和报酬找到同一条。
- 打开一条已发布的夹具配装；私稿和已撤回的记录不会把装备画出来。
- 按作品下载验签的夹具包。
- 在开发开关下登录、看额度、走同步接口。匿名同步会被拒绝。登录后的配装和库存可以推到 PostgreSQL，偏好可以写入账户。
- 打开 `/privacy`。管理员账户可以打开 `/admin`，其他人得到 404。

浏览器抽查（桌面 1440×900、手机 390×844）记录为通过的有：首页、地图、公开配装、私稿不可见、匿名同步 401、主题切换。

### 6.2 下一截要补的页面（不改产品范围）

这些规格里已经写了，当前页面还没接完。补完之后仍然用夹具，直到正式资料进来。

- 收藏可以取消。
- 「复制到我的配装」写入个人库，并保留出处。
- 配装页让人自己选技能、固定或排除装备、打标签和排序，而不是只用写死的夹具条件。
- 未同步的配装在刷新后还在这台浏览器里。
- 本体 / 冰原内容档可以切换。默认列表因此能看到冰原专属条目。
- 活动页接上关注、日历下载；不能推送时仍能在网页里看到提醒。
- 资讯列表接上已有的文章接口。分享用原文或已允许的链接。
- 大厅按武器类型和稀有度筛选，而不是只链到一条夹具。
- 登录前询问是否把访客数据并入账户。
- 页面上能发布和撤回，而不只在接口里能做。
- 地图换上可分发的底图。现在是绘制占位。

明确继续不做，除非以后单独立项：机械武器模拟、猫饭、极限突破、猎虫养成、招式动作值、荒野地图、崛起和物语专区。

### 6.3 要等外部条件的两件事

**正式资料。** 现在的包是合成夹具。要换成可公开使用的实数，需要按作品、平台、补丁做内容清单，并提供允许再分发的来源。`make audit-data` 在没有发行清单时会失败，这是预期。门槛仍是规格里的分开计算：世界含冰原、荒野各自抽样，不把夹具通过说成已经达标。谁提供清单和授权，要内容负责人确认。缺的是资料和授权，不是再写一版界面。

**公网发布。** 生产构建可以在仓库里生成，但没有已核验的公共 HTTPS 地址。应用所有者需要自己：

1. 打开这次应用的预览。
2. 在发布托盘选择 Publish，并确认站点地址。
3. 在 Apps dashboard 的 Access 里把可见性设为 Public。

团队如果关闭了公开分享，要管理员先打开。代理不能代替点击。发布时不要打开测试登录。发布之后，要用没有登录、没有密钥的浏览器再走一遍首页、百科、活动和已发布配装。

**真实会员。** 商业上线要由权利方给出方案和支付渠道。在那之前，产品文案不写价格，不把开发额度写成会员档。

### 6.4 建议的完成顺序

1. 先补第 6.2 节里会让人误以为「已经保存成功」的缺口：收藏可取消、配装刷新不丢、复制进个人库。
2. 再把求解条件从夹具按钮改成猎人可选的技能和装备。
3. 资料授权到位后换正式包，并单独出审计。夹具包继续只用于开发和测试。
4. 所有者发布公网，并关掉测试登录。最后才谈真实支付。
